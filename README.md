# Проект: Облачные технологии и SQL

Этот проект посвящен изучению облачных технологий и баз данных. В качестве основного инструмента для работы с облаком используется платформа Supabase (на базе PostgreSQL). 

В ходе выполнения заданий здесь будут собраны SQL-скрипты для создания таблиц (задачи, сотрудники, курсы, аренда), настройки связей (внешние ключи) и защиты данных с помощью политик безопасности (RLS). 

К концу курса в этом репозитории будет находиться полноценное веб-приложение (список задач) на HTML/JS, которое будет подключаться к нашей облачной базе данных. Также здесь будут храниться все учебные скрипты для проверки ограничений и целостности данных.
